## `$ whoami`

```shell
arturo@freejolitos:~$ cat about.txt
```

Ingeniero mexicano. Dirijo tecnología en **Buzzword** (CTO) y operaciones en **Inovitz** (COO), ambas parte de **GrupoCSI**. Desde 2014 trabajo en **ART** (*Approval in Real Time*), plataforma propietaria de aprobación en tiempo real para crédito y seguros, operada en producción para clientes AAA del sector financiero bajo certificación **CMMI Nivel 5** en los dominios DEV, SVC, SEC y DATA.

Fuera del horario corporativo mantengo **Freejolitos**, una marca personal anclada al software libre, la línea de comandos y los flujos UNIX. También soy fotógrafo con Canon EOS R6.

> *Minimalismo, eficiencia, código bien hecho.*
